## Projetos selecionados — 2025–2026

### 01 — Plataforma Digital de Pós-Graduações Médicas + Integração Hotmart

Pesquisa, coleta, curadoria, normalização e organização de dados de pós-graduações médicas no Brasil, estruturando informações por especialidade e UF.

O trabalho envolveu uso de IA e pesquisa especializada, deduplicação, validação por amostragem e preparação de dados para catálogo digital, PDF interativo e planilha mestre.

Na sequência, foi implementada a integração técnica com a Hotmart por webhook, incluindo testes de compra aprovada e reembolso e validação do fluxo de acesso pela Área de Membros.

**Competências:** Pesquisa com IA · Curadoria de dados · Hotmart · Webhooks · Integração de sistemas · XLSX/PDF

---

### 02 — Gerador de Arquivos CNAB para Google Sheets

Desenvolvimento de uma solução em Google Apps Script para transformar dados de uma planilha de pagamentos em arquivos CNAB.

O projeto contemplou leitura e mapeamento configurável de colunas, validações de campos, datas e formatos, geração do arquivo TXT, interface com menu e sidebar e estrutura preparada para testes e homologação bancária.

O trabalho foi concebido como MVP configurável, com foco em reduzir trabalho manual e facilitar adaptações às particularidades de cada banco.

**Competências:** Google Apps Script · JavaScript · Google Sheets · Automação · CNAB · Validação de dados

---

### 03 — Automação de Marketing Multicanal com n8n

Configuração de uma jornada automatizada de marketing digital, conectando diferentes canais e ferramentas para acompanhar o usuário ao longo do funil.

A solução contempla automações envolvendo e-mail, grupos de WhatsApp e mensagens via API oficial, com eventos e tempos definidos pela estratégia de marketing.

Também foram considerados cenários como carrinho abandonado, mensagens programadas e descadastro, integrando n8n com RD Station e plataformas de comunicação.

**Competências:** n8n · Automação de processos · APIs · Webhooks · RD Station · WhatsApp

---

### 04 — Aplicativo Mobile Multiplataforma — Projeto sob NDA

Participação técnica no desenvolvimento de um MVP mobile multiplataforma utilizando Flutter, com base única para Android e iOS.

A experiência envolveu estruturação de aplicação, persistência local em SQLite, gerenciamento de estado, integração com links compartilhados, validação de URLs, buscas, regras de ranking, construção de interfaces e geração de APK para testes em dispositivo físico.

Por estar protegido por NDA, detalhes sobre produto, negócio e funcionalidades específicas não são divulgados.

**Competências:** Flutter · Dart · SQLite · Desenvolvimento Mobile · Android/iOS · Git

---

### 05 — POC de Monitoramento de Corridas em Tempo Real

Desenvolvimento de uma prova de conceito para avaliar a viabilidade de um aplicativo de transporte com localização em tempo real, gravação iniciada junto à corrida e geração de link compartilhável para acompanhamento por terceiros.

A POC foi estruturada considerando aplicação mobile, geolocalização, armazenamento de dados e comunicação em tempo real, com tecnologias como React Native e Firebase avaliadas para a implementação.

**Competências:** React Native · Firebase · Geolocalização · Desenvolvimento Mobile · APIs · POC

---

### 06 — Planilha Inteligente de Gestão de Risco para Traders

Transformação de uma demanda originalmente relacionada à organização e padronização de materiais de treinamento em uma ferramenta prática de apoio à gestão de risco e disciplina operacional.

A planilha reúne configuração da banca, limites diários de perda e ganho, número máximo de operações, cálculo de tamanho de posição a partir do risco, sugestão de relação risco/retorno e diário simplificado de operações, incluindo registro de emoções e erros/acertos.

**Competências:** Microsoft Excel · Gestão de risco · Modelagem de processos · Automação de cálculos · Gestão financeira · Indicadores

---

### 07 — Calculadoras Interativas para Consultoria de Imagem

Estruturação de duas calculadoras interativas para consultoria de imagem:

* calculadora de estilo baseada em perguntas, imagens e combinações de respostas;
* calculadora de tipo físico baseada em medidas e regras definidas pela consultora.

O protótipo foi pensado para navegação simples, lógica de pontuação, apresentação de resultados, entrada de medidas e exportação de dados, utilizando tecnologias web como HTML e JavaScript.

**Competências:** HTML · JavaScript · Desenvolvimento Web · UX · Interfaces Interativas · Lógica de programação

---

### 08 — Implantação de Plataforma de Cursos Online — Astron Members

Estruturação de uma plataforma de cursos online, incluindo configuração da área de membros, organização de cursos e aulas, estruturação inicial do site, integração com recursos externos e redes sociais e preparação do ambiente para operação.

O trabalho também envolveu organização do conteúdo existente e orientação para que os responsáveis pudessem administrar posteriormente a plataforma, inserir vídeos, liberar aulas e manter o ambiente.

**Competências:** Plataformas EAD · Desenvolvimento Web · Conteúdo Digital · DNS · Integração de sistemas · Treinamento

---

### 09 — Migração Estruturada de SharePoint para Google Drive

Execução de uma migração estruturada de documentos entre Microsoft SharePoint e Google Drive, preservando a organização de pastas, subpastas e arquivos.

O trabalho incluiu coleta dos documentos, transferência para o novo ambiente, preservação dos nomes e estrutura e verificação da integridade do conteúdo após a migração.

**Competências:** SharePoint · Google Drive · Migração de dados · Gestão documental · Organização de arquivos · Validação
